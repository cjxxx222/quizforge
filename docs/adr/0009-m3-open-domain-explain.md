# 9. M3 讲解增强：开放域检索（而非课件闭域）

- 状态：已接受（M3）
- 背景：方案 V2 原定 M3 用"课件语料检索"（闭域）。但用户手上只有题库 PDF、无课件语料；且实测本机网络下 DuckDuckGo 超时、维基百科超时、百度百科 403（安全验证）、Bing 搜索页返回降级内容——免费无 key 的检索源全部不可用。
- 决策：
  1. 检索源用**博查（Bochaai）Web Search API**（国内官方接口，网络可达，返回结构化结果且自带 summary 字段可直接作检索上下文）；
  2. 搜索做成**可插拔适配器**（`SearchProvider` 接口），换源不改业务逻辑；
  3. **网页快照落库**（url + title + domain + content + fetched_at）——解决"网页会改会删导致引用失效"，引用变成可验证的存档；
  4. **来源白名单分层重排**（tier1 权威 / tier2 教学资源 / tier3 其他 + 同域名限 2 条），应对开放域"口径不一致"风险；
  5. **反幻觉约束**：上下文只含检索结果、强制引用编号、资料不足必须明说；无检索支撑时降级为 LLM 直讲并**明确标注"非教材口径、无引用"**。
- 备选与放弃：360 搜索页抓取（实测可解析，但违反 ToS、页面改版即崩、公开仓库中属工程判断力减分项）；纯 LLM 直讲（无引用，不构成检索增强）。
- 后果（实测数据）：
  - grounded_rate 1.0、citation_coverage 1.0；
  - **白名单命中率仅 23.5%**（tier1=0/tier2=4/tier3=13）——开放域对语文知识点的来源质量偏低，这是闭域检索的优势所在，量化暴露了本路线的固有代价；
  - 查询引导实验：query 追加"知识点 讲解 教材"后，同批题目白名单命中率 **23.5% → 55.6%**（对照实验，已设为默认 `EXPLAIN_QUERY_HINT`）；
  - 评测口径相应改写：开放域无法计算 Recall@5（无固定正确块集合），改用 grounded_rate / citation_coverage / whitelist_hit_rate。
